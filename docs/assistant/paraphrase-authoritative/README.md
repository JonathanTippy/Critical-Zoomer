# Paraphrase authoritative

Developer-owned prose lives in `docs/authoritative/` and must not be mixed with
assistant-written text.

This folder holds **LLM paraphrases** of intent captured in conversation: design
policy restated for implementation, without editing the developer's original
words. Treat these as working notes that track what was decided; when the
developer promotes something into `authoritative/`, that version wins.
